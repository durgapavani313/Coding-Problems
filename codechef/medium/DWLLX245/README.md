## Problem

### Check if a Number is Positive or Negative

In this example, we demonstrate how to use the ternary operator to check whether a number is positive or negative. The program will evaluate the number using the  **ternary operator**  and print the corresponding result.

 **When executed the code will show:** 

```
The number is positive.

```

## Solution

**Language:** c_cpp  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-11-17T13:48:16.303Z  

```c_cpp
#include <stdio.h>

int main() {
    int number = 5;

    // Using ternary operator to check if the number is positive or negative
    (number >= 0) ? printf("The number is positive.\n") : printf("The number is negative.\n");

    return 0;
}

```
