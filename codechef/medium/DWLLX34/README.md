## Problem

### Displaying Product Quantity

Write a C program to declare and initialize a variable for a product's quantity. Display the value stored.

 **Expected Output:** 

```
Product Quantity: 50

```

## Solution

**Language:** c_cpp  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-11-11T14:38:12.979Z  

```c_cpp
#include <stdio.h>

int main() {
    int Product_Quantity;
    Product_Quantity = 50;
    printf("Product Quantity: %d",Product_Quantity);
    return 0;
}
```
