## Problem

### Declare arrays for student grades and days of week

In this example, we demonstrate how to declare arrays in C to store student grades and days of the week. An `int` array is used to hold 5 student grades, and a `char` array is used to represent 7 days.

 **When executed, the code will show:** 

```
Arrays declared successfully!

```

## Solution

**Language:** c_cpp  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-11-20T00:36:09.359Z

#include <stdio.h>

int main() {
    // Declare an integer array for 5 student grades
    int grades[5];
