## Problem

### Display Quote

Write a program to print a motivational quote using escape sequences like `\t` for tabs, `\n` for newlines, `\"` for quotes. Code blocks `{}` are used to group related print statements, making the code more organized.

 **Expected Output:** 

```
Displaying a famous quote:
	"Success is not final,
	failure is not fatal:
	It is the courage to continue that counts."

```

## Solution

**Language:** c_cpp  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-11-10T13:07:59.191Z  

```c_cpp
#include <stdio.h>

int main() {
    
    printf("Displaying a famous quote:\n");
    printf("\t\"Success is not final,\n");
    printf("\tfailure is not fatal:\n");
    printf("\tIt is the courage to continue that counts.\"\n");

    return 0;
}
```
